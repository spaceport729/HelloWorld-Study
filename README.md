# Hello, World

A world map for getting to know each country through joy and beauty: a word worth knowing, something to ask, common ground, music, festivals, crafts, wildlife and food.

Live app: https://spaceport729.github.io/HelloWorld-Study/ (open in Safari, then Share → Add to Home Screen).

This repository holds only the published app. The country notes are written in Stacey's Obsidian vault (the private `spaceport` repository, `HelloWorld/`), and `HelloWorld/_app/build_countries.py` there generates `data/countries.json`. Don't edit the files here by hand; they're copied from `spaceport/HelloWorld/_app/`.
